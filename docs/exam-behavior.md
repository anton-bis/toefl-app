# 模考交互规则

## 作答阶段

- 作答过程中不提供答案检查或正确答案提示。
- Reading 可通过 `Questions` 查看当前 Module 的已答、未答和标记状态，并在当前 Module 内跳题。
- Writing 的 Build a Sentence 可通过 `Questions` 在当前 Task 内跳题；其他 Writing Task 不显示题目导航。
- Listening 按顺序作答，不允许返回已经离开的题目。题目超时后锁定当前答案并自动进入下一题，不显示正确答案。
- Speaking 按录音流程顺序进行，不提供题目标记或跳题。
- 答案和当前进度自动保存；完成的考试不可继续修改。

## 答案复盘与报告

- 正确答案只在科目完成后的 `Review Answers` 中显示。
- 答案复盘完全只读，只能在相邻题目间移动或返回 `Results`。
- `mode=report` 只对已经完成的科目有效；未完成科目不得通过报告 URL 查看答案。
- 跨科报告只包含同一 TPO 中已经完成的科目。
- Restart 会清除报告查询参数并创建新的可作答会话。

## 明确不提供

- 作答中的 `Check Answers`
- 作答中的正确率统计和正确答案揭示
- 仅重做错题
- Listening/Speaking 的返回或题目跳转
