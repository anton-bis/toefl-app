## 1. 产品定位

面向托福考生的口语与写作专项练习 + AI 批改平台。**做题免费，AI 批改收费。**

核心价值：
- 按话题/题型/套题三种维度组织题目，方便考生精准找到想练的内容
- 写作和口语（Interview 题型）提供 AI 评分 + 分项反馈 + AI 润色版
- Listen & Repeat 题型提供 AI 评分 + 发音/连读/口误检测，展示专业度
- 每一次批改记录永久保存，供用户回顾温习

---

## 2. 练习模式

三种模式并行，题库数据互通，互相打通。

### 2.1 分科练习

按阅读/听力/口语/写作四科分类，自由切换练习。客观题自动判对错，免费使用。

### 2.2 套题模考

保留现有 TPO 01-09 套题形式，按考试编号完整练习。后续导入新真题时按考试时间归档。

### 2.3 话题分类

跨 TPO 按话题筛选（生物、地理、天文、历史、艺术等），支持题型筛选和模糊搜索。

### 2.4 搜索

支持关键词搜索题目内容，按话题/题型/考试时间多维度检索。

---

## 3. 练习流程

### 3.1 客观题（阅读/听力）

```
用户选题 → 作答 → 提交 → 自动判对错 → 展示答案 + 解析
费用：免费
```

### 3.2 写作

```
用户选题 → 在线写作文 → 提交
  → AI 评分（0-5 制 + 各维度分项）
  → 分项反馈（词汇/语法/结构/内容等改进建议）
  → AI 润色版（基于用户原文逐句优化）
  → 保存至历史记录
费用：按次扣费 / 包月不限次
```

### 3.3 口语 — Interview 题型

```
用户选题 → 录音上传 → 提交
  → AI 评分（0-5 制 + 各维度分项）
  → 分项反馈（内容组织/表达方式/语法/词汇等改进建议）
  → AI 润色版（基于用户回答输出优化版本）
  → 保存至历史记录
费用：按次扣费 / 包月不限次
```

### 3.4 口语 — Listen & Repeat 题型

```
用户选题 → 听音频 → 录音复述 → 提交
  → AI 评分（准确度/完整度/清晰度）
  → 分项反馈（发音/连读/口误/语调检测）
  → 不提供润色版（复述无润色意义）
  → 保存至历史记录
费用：按次扣费 / 包月不限次
```

## 4. 评分报告

每次 AI 批改完成后展示：

| 内容 | 写作 | 口语-Interview | 口语-Listen & Repeat |
|------|------|---------------|---------------------|
| 0-5 分制评分 | ✅ | ✅ | ✅ |
| 30 分/6 分制换算 | ✅ | ✅ | ✅ |
| 各维度分项分数 | ✅ | ✅ | ✅ |
| 逐条改进建议 | ✅ | ✅ | ✅（发音/连读/口误） |
| AI 润色版 | ✅ | ✅ | ❌ |
| 用户原文保留 | ✅ | ✅ | ✅ |

## 8. 数据可靠性

- 用户提交的作文文本或口语录音**先存入数据库，再调 AI API**
- API 调用失败时，用户原文不丢失，标记为"待评分"，可稍后重试
- API 失败提示语人性化安抚："你写的内容没有任何问题，是我们的 AI 暂时忙不过来了 🙏"

## 10. 技术架构

### 第一阶段（免费验证期）

```
GitHub 仓库 → Vercel（免费）→ Vue 3 前端
           → Railway 免费额度 → Express 后端 + MySQL
```

### 第二阶段（用户增长后）

```
迁移至阿里云/腾讯云轻量服务器（¥34/月起）
```

### 数据流

```
用户提交 → 存入 MySQL → 调 DeepSeek/智谱 API
  ├─ 成功 → 评分结果存入 MySQL → 渲染报告
  └─ 失败 → 标记"待评分" → 用户可重试
```
